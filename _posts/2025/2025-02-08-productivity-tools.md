# Introduction

This last days I reached the limit of Notion, which is a website that provides you an editor where you can organize your files as folders, add tables, headers, images and many other resources to create documents. 

I really enjoyed to create things there. Some example of things that I create there were: 

- Sermons and bible studies
- Wine and Beers score
- Receips
- etc.

I really anjoyed and if it was a reasonable price I would happylly pay it. Although, since I leave, work and earn in Brazil, the dollar value is a bit expensive for me. This is why I'll start a journey trying to identify possible tools to track everything that I do in easy way.

# Strategy

In order to figure out the possible substitutes for Notion, I'll follow the steps bellow:

1. List everything that I want to use it for
2. List features required to accomplish the tasks in 1.
3. Check what type of tools I can try
4. For each type of tool, check the available tools that meet requirements of 2. step.
