# Introduction

I'm kinda having some problems with refactoring latelly. There are a lot of tickets of refactoring that will prepare the code to receive new functionalities. 
The biggest problem is that it's hard to provide evidences of the outcome of the task. If the refactoring was good or bad, if we had to add many auto tests or unit tests to assure the code behavior will not change, all this work is not easy to present to stakeholders. So, this is an study about the Refactoring topic to search a solution for this.
